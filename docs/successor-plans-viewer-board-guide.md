# Active and Archived plans: Viewer and Board guide

Audience: Viewer and Board-role users

## What changes when a successor is activated

The product always has one **Active Strategic Plan**. Overview and normal
Reports use that plan. When an Admin activates a successor, the former Active
plan becomes **Archived** and the successor becomes Active as one change.

Your account and role do not change. You are not normally signed out. Refresh
or use the main navigation to see the new Active plan.

Draft and Cancelled plans are Admin-only. You will not see planning work before
activation.

## Viewer access

A Viewer can:

- read the full Active-plan Overview and Reports;
- open Priority and Measure details;
- open Archived Plan Review for a prior Active plan; and
- download the available CSV, PNG, and PDF reports for the plan being viewed.

A Viewer cannot:

- open Setup → Plans;
- see a Draft or Cancelled plan;
- change plan content or results;
- activate or cancel a plan; or
- use Data Entry.

## Board access

A Board account can:

- read the Active plan's approved Board scope;
- open the linked Priority and Measure details within that scope;
- open an Archived plan's preserved Board report; and
- download that plan's approved Board exports.

A Board account cannot:

- see the full staff report when it is outside Board scope;
- see or preview a Draft;
- open Setup or Data Entry; or
- change Board scope.

Board scope belongs to each Strategic Plan. An Archived report uses the titles,
focus statements, and Measure links approved for that plan. It does not use the
current plan's Board settings.

If an Admin deliberately activates a plan with no Board report, Board users see
a clear **No Board report configured** message.

## Open a prior plan

In **Reports**, use the plan selector:

1. keep **Active** selected for current reporting;
2. choose a plan under **Archived** to open its historical report; and
3. use **Return to Active plan** when finished.

Archived review applies only to that Reports link. It does not become a
remembered app-wide selection. Overview, Data Entry, ordinary Reports
navigation, and a new sign-in use the Active plan.

An Archived plan is read-only. It includes its own:

- Reporting Years;
- Priorities, Goals, and Measures;
- definitions and Targets;
- recorded results and notes;
- Board scope;
- incomplete or missing reporting labels; and
- CSV, PNG, and PDF exports.

The product reconstructs historical reports from the Archived plan's preserved
records. The report identifies the historical Reporting Period and when the
output was generated.

## How to interpret historical reports

Historical wording is intentional. A renamed Measure or changed Target in the
new Active plan does not rewrite an Archived plan.

Missing or unfinished information remains visible as **Not reported** or
**Incomplete**. It is not hidden to make the plan appear more complete, and it
is never treated as zero.

Copied or related definitions in a successor remain separate records. Results
are not combined across plans merely because two items have similar names or a
“Copied from” relationship.

## Exports

Export from the report currently shown on screen. Confirm the plan name and
Reporting Period before sharing the file.

- A Viewer receives the full report available to staff for that plan.
- A Board account receives only that plan's preserved Board scope.

An Archived export uses the Archived plan's language and scope, not the current
Active plan's settings.

## If something looks wrong

- **You expected a Draft:** Drafts are Admin-only and do not appear in normal
  reporting.
- **A prior plan is missing:** only plans that were once Active appear under
  Archived; Cancelled Drafts are not historical performance plans.
- **The report changed after activation:** check the plan label. Normal
  navigation now uses the new Active plan.
- **A Board item is missing:** ask an Admin to confirm the Board scope for the
  plan you are viewing.
- **A historical value looks incomplete:** read its Not reported or Incomplete
  explanation; do not substitute a current-plan result.
- **Saving or the website is unavailable:** stop and contact the system
  operator. Viewer and Board accounts should not attempt recovery.
